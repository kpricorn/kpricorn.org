# kpricorn.org

One screen, no build step, no dependencies, no trackers.

- `index.html` – a dot-matrix display across the whole screen (tap to advance, the dots bulge under the pointer), the sky tinted by the time in Zürich, a name and five links
- `404.html`, `favicon.svg`
- `deploy.sh` – copies the three files into `public/` (the `kpricorn/kpricorn.github.io` submodule) and pushes

Open `index.html` in a browser to preview.
