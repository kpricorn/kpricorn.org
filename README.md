# kpricorn.org

One page, no build step, no dependencies, no trackers.

- `index.html` – the landing page: everything inline, the SVG animations are CSS only
- `404.html`, `favicon.svg`
- `deploy.sh` – copies the three files into `public/` (the `kpricorn/kpricorn.github.io` submodule) and pushes

Open `index.html` in a browser to preview.
